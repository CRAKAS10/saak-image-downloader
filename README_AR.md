# منزّل صور منتجات ساك — تطبيق سطح مكتب v2.0

تطبيق Windows بواجهة عربية يستعرض صفحات المنتجات العامة في `https://www.saak.com.sa/ar/منتجاتنا`، ويحمّل صور المنتجات بجودتها الأصلية في مجلدات حسب الفئة، مع فهرس `image_index.csv` وأرشيف ZIP.

## التشغيل
| الطريقة | الخطوات |
|---|---|
| ملف EXE (موصى به) | شغّل `dist\SAAK_Image_Downloader.exe` بعد البناء، ولا يحتاج Python |
| بناء EXE | انقر مزدوجًا على `build_exe.bat`، ويتطلب Python 3.10+ |
| تشغيل مباشر | انقر مزدوجًا على `run_app.bat` |
| سطر الأوامر | `python saak_engine.py --out D:\SAAK --max-pages 300` |

## ما أُضيف على السكربت الأصلي
- واجهة رسومية عربية: إعدادات، أزرار بدء/إيقاف، عدادات حيّة، سجل، فتح المجلد/CSV.
- إيقاف آمن في أي لحظة مع حفظ الفهرس.
- **استكمال**: إعادة التشغيل تتخطى الصور المحفوظة سابقًا.
- منع التكرار بالبصمة SHA1 للمحتوى (نفس الصورة بروابط مختلفة).
- إعادة المحاولة عند فشل الشبكة.
- احترام robots.txt (اختياري).
- معالجة صحيحة للنص العربي عند غياب ترميز الصفحة.
- تسمية مجلد الفئة من المقطع التالي لـ `/منتجاتنا`.
- دعم `data-original` و srcset الكسري، وكلمات استبعاد مخصصة.
- حفظ الإعدادات تلقائيًا في `%APPDATA%\SAAK_Downloader`.

## ملاحظات
- الصور ملك لشركة ساك؛ استخدمها داخليًا ولا تعِد نشرها دون إذن.
- راجع الفهرس، فبعض الصور قد تكون بنرات وليست عبوات.
