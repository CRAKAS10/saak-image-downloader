# Product Image Downloader v2.1 — منزّل صور المنتجات من المواقع

تطبيق Windows بواجهة عربية: الصق رابط **أي موقع أو صفحة منتجات**، فيستعرض الصفحات ويحمّل الصور بجودتها الأصلية في مجلد مستقل لكل موقع، مع فهرس `image_index.csv` وأرشيف ZIP.

**التحميل:** [Releases](../../releases/latest) ← `Product_Image_Downloader.exe` (لا يحتاج Python)

## الإعدادات
| الخيار | الوظيفة |
|---|---|
| رابط الموقع / الصفحة | أي رابط؛ يُضاف `https://` تلقائيًا، وإن فشل يُجرَّب `http://` |
| مرشح المسار (اختياري) | مثال `/products` أو `/منتجاتنا` لحصر الزحف في هذا المسار |
| البقاء داخل مسار الرابط | عند تفعيله دون مرشح يبقى الزحف تحت مجلد الرابط؛ ألغِه لزحف الموقع كاملًا |
| قبول صور CDN | يسمح بالصور المستضافة على نطاقات أخرى |
| احترام robots.txt | يتخطى الصفحات التي يمنعها الموقع |

## ملاحظات
- الصفحات التي تُحمّل صورها بـ JavaScript فقط قد لا تظهر صورها.
- الصور ملك أصحاب المواقع؛ استخدمها داخليًا ولا تُعِد نشرها دون إذن.
- سطر الأوامر: `python saak_engine.py --url example.com/shop --whole-site`
